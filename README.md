# 💰 SmartSpend – Personal Expense Tracker

A console-based Personal Expense Tracker built using C language.

SmartSpend helps users manage their daily finances by recording income and expenses, tracking transactions, and calculating their current balance.

## ✨ Features

- ➕ Add Income and Expenses
- 📋 View Transaction History
- 📊 Financial Summary
- 🔍 Search Transactions
- ✏️ Edit Existing Transactions
- 🗑️ Delete Transactions
- 💾 Save and Load Data using File Handling

## 🛠️ Technologies Used

- C Programming Language
- Structures
- Functions
- File Handling
- Arrays

## 🚀 How to Run

1. Download `smartspend.c`.
2. Open it in a C compiler.
3. Compile and run the program.

## 🎯 Project Objective

This project was developed to practice C programming concepts and understand how file handling can be used to build a practical application.
